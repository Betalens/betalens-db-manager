行业历史提取与版本安全
====================

``scripts/extract_industry_history.py`` 使用管理器真实来源适配器，归档所有请求、
响应哈希和连续分页链。申万旧版通过明确 SW2014 字典与 ``index_member`` 查询，
新版通过 SW2021 字典与 ``index_member_all`` 查询，中信通过 ``ci_index_member``。
每个范围必须读到末尾空页；分层提取集合另与独立全市场响应核对。

``index_member_all`` 不提供版本选择参数。通用处理器只能在完整 SW2021 字典的
代码、名称、层级、父级均匹配时产生 SW2021 记录；不能根据成员纳入年份改标 SW2014。
管理器自动冻结、先提取并向各转换批次传递三级字典依赖。缺少字典时阻止转换。
``index_classify`` 返回泛称 SW 时，以已归档的显式 src 请求为版本依据。

``scripts/import_industry_history.py`` 默认只投影审计，显式 ``--execute`` 才通过
管理器文件导入管线向双库提交。方案研究窗口独立于历史公开时间；窗口列仅为可空增列，
不重建表、不重写原方案 event_date/available_at。空区间隔离并保留原始来源，反向区间
和字典冲突仍阻止入库。重叠源区间原样保存，下游查询歧义时严格报错。

研究窗口为 SW2014 ``[2005-01-01,2021-12-13)``、SW2021 ``[2021-12-13,+∞)``；
中信自 2005 年起独立追溯。SW2014 发布前的窗口属于用户明确选择的追溯研究，
不是严格 PIT 证据。原始成员有效期不截断、不伪造。

``scripts/audit_industry_labels.py`` 对普通表与行业版本表做双库全表版本抽查和快照。
``scripts/repair_industry_version_labels.py`` 将旧处理器从无版本分级接口推断的
SW2014 归属降为未知。纠正通过管理器追加、校验、发布新修订，只影响 SW2014 范围；
旧发布、原文、源哈希和真实下载时间保持不变。缺失传输归档不伪装成重新获取成功，
质量纠正仅依据已核验的不可变发布，不增加来源事实或可得时间声明。
